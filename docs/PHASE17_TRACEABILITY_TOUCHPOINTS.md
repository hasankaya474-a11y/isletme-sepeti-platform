# Phase 17 Traceability / Location Pilot Touchpoints
Status: ACTIVE FOUNDATION
Date: 2026-09-29

- Live-location collection is disabled unless an active pilot enrollment has explicit location consent.
- Withdrawal immediately disables future location samples.
- Location samples are purpose-limited to the pilot/delivery context.
- Traceability events are append-only evidence.
- Location data is not used for advertising or unrelated profiling.
- Location does not authorize order, price, supplier or payment changes.
- Help content must explain consent, withdrawal, trace events, location accuracy and retention.
- Production remains locked.
