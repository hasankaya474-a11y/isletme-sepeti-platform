# Vitrin Studio
Status: FOUNDATION IMPLEMENTED

Authorized Admin users can manage pages through predefined safe blocks rather than arbitrary code. Initial block set: Hero, Text, Image, Category Grid, Product Showcase, Banner, CTA, FAQ, Form and Help.

Blocks support ordering, content, visibility and scheduling metadata. Media supports separate desktop/mobile references and dependency checks before archival. SEO has controlled metadata validation and slug normalization.

Required next: block field schemas, live preview renderer, publish/version binding, media upload security pipeline, SEO/redirect center and API/Admin action wiring.
