## Decision rationale
Explain why the gate is PASS or FAIL.

## Required gate-specific content

### SECURITY_REVIEW
Include security assessment / penetration-test reference and unresolved critical/high findings.

### LEGAL_REVIEW
Include terms, contracts, supplier/buyer obligations, dispute/evidence workflow and applicable legal-document review reference.

### ACCOUNTING_REVIEW
Include invoice, tax, commission, ledger, reconciliation and accounting-process review reference.

### PRIVACY_REVIEW
Include retention, support/case data, exports, audit data and optional location-pilot data review reference.

Repository tests alone are not sufficient evidence for these external gates.
