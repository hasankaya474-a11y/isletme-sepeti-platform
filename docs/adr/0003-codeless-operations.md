# ADR-0003: Codeless Normal Operations

Status: Accepted
Date: 2026-09-28

If an existing capability needs source-code changes for ordinary daily management, that capability is incomplete.

Admin-managed areas include catalog content, storefront content, media, help, publish state, campaigns, notification templates, permitted pricing/stock/configuration rules, approvals and operational settings.

New platform capability, schema evolution and security protocols remain engineering changes.
